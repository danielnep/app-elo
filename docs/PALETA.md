# Design tokens App Elo

O azul bebê original da referência foi intensificado visualmente em aproximadamente 15% na saturação e matiz deslocada ligeiramente para azul, preservando a luminosidade percebida; não usar azul-marinho/ciano escuro como cor principal.

```css
:root {
 --elo-blue: #84CFFF;
 --elo-pink: #F6A1CD;
 --elo-pink-action: #FF84BE;
 --elo-white: #FFFFFF;
 --elo-bg: #101319;
 --elo-surface: #1B202A;
 --elo-elevated: #262C37;
 --elo-border: #424956;
 --elo-text-secondary: #C7D0DA;
 --elo-brand-gradient: linear-gradient(120deg, #84CFFF 0%, #FFFFFF 50%, #F6A1CD 100%);
}
```

Modo padrão dark premium, ícones discretos; gradientes decorativos nunca sob texto de baixo contraste. Botões primários rosa, ações complementares azul; chip ativo com preenchimento rosa claro e texto escuro. Verificar WCAG AA (texto 4.5:1, controles 3:1 quando aplicável). Textos são sempre pt-BR. Recursos visuais com pessoas diversas e 18+, sem estereótipos. Prezar densidade e legibilidade acima de reprodução literal de texto imperfeito do mockup gerado por IA.
